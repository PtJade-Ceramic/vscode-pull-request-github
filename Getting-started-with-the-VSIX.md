1. Install latest VS Code Insiders
1. install the vsix from https://github.com/Microsoft/vscode-pull-request-github/releases/tag/v0.0.1
2. Reload VS Code after the installation (click the reload button next to the extension)
3. Exit VS Code.
4. Start VS Code Insiders from command line with flag: `code-insiders --enable-proposed-api Microsoft.vscode-pull-request-github`
5. You should be good to go!
